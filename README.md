
# 📊 Interactive Sales Dashboard | Power BI

## 📌 Project Overview
This project is an interactive Sales Dashboard developed using Microsoft Power BI to analyze sales performance, track key performance indicators (KPIs), identify trends and provide meaningful insights through data visualization.

The dashboard uses data transformation, data modelling and DAX measures to present sales data in an interactive and user-friendly format.

## 🎯 Project Objectives
- Analyze overall sales performance and trends.
- Track key business metrics and KPIs.
- Explore sales performance across different categories and dimensions.
- Create interactive visualizations for data exploration.
- Support data-driven decision-making through analytical reporting.

## 🛠️ Tools & Technologies
- **Power BI Desktop** – Dashboard development and data visualization
- **DAX** – Calculated measures and KPI calculations
- **Power Query** – Data cleaning and transformation
- **Data Modelling** – Data relationships and model organization
- **Data Visualization** – Interactive charts, slicers and KPI cards

## 📈 Dashboard Features
- Interactive KPI cards for key sales metrics.
- Sales performance analysis.
- Category-wise and product-wise sales visualization.
- Sales trend analysis.
- Interactive slicers and filters for dynamic exploration.
- Comparative analysis across different sales dimensions.
- User-friendly dashboard design.

## 🧮 DAX & Data Analysis
- Created DAX measures to calculate key performance indicators.
- Used calculations to support sales performance analysis.
- Applied DAX measures within dashboard visuals for dynamic reporting.
- Enabled interactive analysis through slicers and visual-level interactions.

## 🔄 Data Preparation
- Cleaned and transformed data using Power Query.
- Prepared datasets for analysis and visualization.
- Organized data and relationships for reporting.

## 🔍 Key Analysis
The dashboard allows users to explore:
- Sales performance across categories.
- Product-level performance.
- Sales trends over time.
- Performance across different available dimensions.
- Key business metrics through interactive visuals.
